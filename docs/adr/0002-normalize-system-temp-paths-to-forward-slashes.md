# ADR-002: Normalize System Temp Paths to Forward Slashes

*This markdown document was generated with the assistance of a large language model. Reviewed by the maintainer --- Andrew D. France.*

**FYR:**

- *Format:* [*Michael Nygard's ADR template*](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions "null")

**Status:** Accepted

**Context:**

The `get-tempfile` function handles the creation of temporary scripts and data files required to pipe information from Lua/Fennel into Gnuplot. It constructs these paths by reading the system's temp directory (via `os.getenv("TMP")` or `os.getenv("TEMP")`) and concatenating it with a forward slash and a generated filename.

On Windows, these environment variables typically return paths with backslashes (e.g., `C:\Users\Name\AppData\Local\Temp`). Blindly concatenating a forward slash resulted in mixed-slash paths (e.g., `C:\...\Temp/fplot-12345.gp`). While the Lua/C I/O libraries generally tolerate mixed slashes, it is messy, inconsistent, and creates an unnecessary surface area for path-parsing bugs.

**Decision:**

Normalize the temporary path string inside `get-tempfile` before concatenation. Use Lua's `string.gsub` to replace all backslashes (`\`) with forward slashes (`/`) on the raw string pulled from the environment variables.

```
;; Before
(let [tmp (or (os.getenv "TMP") (os.getenv "TEMP") ".")
      name (if (= tmp ".") ... (.. tmp "/" prefix ...))] ...)

;; After
(let [raw-tmp (or (os.getenv "TMP") (os.getenv "TEMP") ".")
      tmp (string.gsub raw-tmp "\\" "/")
      name (if (= tmp ".") ... (.. tmp "/" prefix ...))] ...)
```

**Consequences:**

- All temporary paths generated by `fplot` are now perfectly uniform, utilizing forward slashes regardless of the host operating system.
  
- Completely eliminates the risk of Gnuplot or underlying OS APIs mishandling backslashes in temporary file execution.
  
- Simplifies cross-platform debugging, as the generated script paths look identical across Linux, macOS, and Windows.
